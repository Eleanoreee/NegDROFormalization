\section{Source and Verification Map}
\label{app:version-map}

This note uses arXiv:2412.11850v3, revised January~7, 2026, as the canonical
source for the original NegDRO formulation and its empirical algorithms.  The
fresh-sample projected-SGD/EG theorem is an extension developed in this note.
The table separates inherited source material, verified extension results,
retained model assumptions, and out-of-scope constructions.

\begin{center}

\toprule
